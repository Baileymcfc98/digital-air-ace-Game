# Fast upload guide

## Method 1: Upload through the GitHub website

1. Create a new repository.
2. Select **Add file → Upload files**.
3. Drag these three files into the upload area:
   - `index.html`
   - `README.md`
   - `.nojekyll`
4. Select **Commit changes**.
5. Open **Settings → Pages**.
6. Choose **Deploy from a branch**.
7. Select `main` and `/ (root)`.
8. Select **Save**.

## Method 2: Use GitHub Desktop

1. Extract the package.
2. Add the extracted folder as a local repository.
3. Publish the repository to GitHub.
4. Enable GitHub Pages from `main` and `/ (root)`.

## Important leaderboard note

Scores are stored locally in each browser. They are not shared between different laptops, tablets or browsers.
